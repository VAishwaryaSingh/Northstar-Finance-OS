# Northstar Finance OS

**AI-Native ERP & Month-End Close Implementation POC**

> Northstar Finance OS is an end-to-end finance transformation proof of concept for a fictional multi-entity healthcare group. It demonstrates how accounting process discovery can be translated into finance-system architecture, SQL data modelling, Python automation, REST API integration, reconciliation, AI-assisted accounting workflows and implementation planning.

**Status: early scaffold.** See the `STATUS` block at the top of [`PLAN.md`](./PLAN.md) for what's built so far — this README will be filled out fully (problem, architecture, demo, learnings) as each phase lands. Full specification and build sequence live in [`PLAN.md`](./PLAN.md) and [`AGENTS.md`](./AGENTS.md).

**Everything in this project — the client, entities, and data — is fictional.** It is a portfolio project, not production software, and was never built for or with a real company's data.

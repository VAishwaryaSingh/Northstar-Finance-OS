# AI Accounting Assistant — Northstar Finance OS

Implements PLAN.md §24's AI-assisted workflow and §25's safety policy — built and evaluated **fully offline** in this session (no LLM API calls made, no API key configured), by explicit choice. See `controls.md`'s "Known limitations" and below for what that means and how to switch it on later.

## Run it

```bash
.venv/bin/pytest 09-ai/tests -v    # 13 tests, no network/database needed
.venv/bin/python 09-ai/evaluate.py # regenerates evaluation-results.md
```

## The core design decision: rules first, AI second, always checked

This module never gets to decide anything on its own. `process_invoice()` calls `08-accounting-automation/invoice_classification.classify_vendor_account` — the *same* deterministic rule every other posting path in this project uses — to check the AI's suggestion, not a second copy of that rule that could quietly disagree with the first. Confidence, the approval threshold (also reused from Phase 11, not reinvented), and a no-hallucinated-data check all sit alongside it. Every one of these has to pass before `requires_human_review` comes back `False`. See `controls.md` for the full mapping and `evaluation.md`'s EVAL-010 case for an honest discussion of what still isn't caught.

## Going live with a real model

Everything above uses `MockLLMClient` — a deterministic lookup table of canned responses, not a real model. That's not a placeholder for something missing; it's the same reason any serious codebase mocks external APIs in its test suite (so tests are free, fast, and don't depend on network access). `AnthropicLLMClient` is a complete, correct implementation using Claude Haiku 4.5 (chosen for cost — this is a bounded classification task, not open-ended reasoning) with strict, schema-validated tool use so its output always matches what `process_invoice` expects.

To actually run it against real invoices:

```bash
export ANTHROPIC_API_KEY=your-key-here   # never commit this -- see .env.example
```

```python
from llm_client import AnthropicLLMClient
from accounting_agent import process_invoice

client = AnthropicLLMClient()
result = process_invoice(invoice, client, known_accounts, known_entities,
                          vendor_default_account_code=..., amount=...)
```

Cost is a small fraction of a cent per invoice at Haiku 4.5's pricing — see `prompts.md`'s "Model choice" section. `evaluate.py` would need `AnthropicLLMClient` swapped in for `MockLLMClient` in `run_case()` to produce real model numbers (same methodology, same metrics, real input).
